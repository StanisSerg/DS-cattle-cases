# Пенсильванские сита

> Шаблон для ввода данных физической структуры TMR (Pennsylvania State Particle Separator, PSPS) — образец CASE-002.
> Каждое посещение — отдельный файл: `psps_visitNN_YYYY-MM-DD.md` (переименовать по факту визита).
> Сита и СВ дублируются в АМТС (B-01.D-03 §1.3).

## Параметры измерения

- **Ферма / комплекс:** Шени-Агропродукт
- **Метод:** просеивание TMR через сита PSPS
