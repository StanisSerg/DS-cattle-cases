# Навозные сита

> Шаблон для ввода данных навозных сит (переменный набор B-01.D-03 §2).
> Триггер: подозрение на ацидоз; смена рациона (новые траншеи, новый комбикорм); планово — 1 раз в 3 недели.
> Каждое посещение — отдельный файл: `navoznye_sita_visitNN_YYYY-MM-DD.md` (переименовать по факту визита).

## Параметры измерения

- **Ферма / комплекс:** Шени-Агропродукт
- **Метод:** просеивание навоза через набор сит
