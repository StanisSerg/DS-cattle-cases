# Excel-отчёты DairyPlan (CASE-002)

Приёмная папка для Excel-отчётов из DairyPlan (WP-118).

## Правила приёма

- Сюда — только исходные `.xlsx` из DairyPlan (как выгружены, без ручных правок).
- Имя файла = дата, **на которую** данные: `YYYY-MM-DD.xlsx` (отчёт может формироваться позже — см. пересчёт ниже).

## Правила обработки (решения пилота 2026-09-07)

Конвертация в md-таблицу — скриптом `scripts/dairyplan_to_md.py` (корень репо):

```bash
python3 scripts/dairyplan_to_md.py cases/CASE-002-zencht-leninsky-dynamics \
    cases/CASE-002-zencht-leninsky-dynamics/raw/excel/2025-01-01.xlsx
# дата выгрузки по умолчанию = день запуска; переопределить: --report-date YYYY-MM-DD
```

1. **Пересчёт «День лактации».** DairyPlan при формировании отчёта считает, что коровы доятся до даты выгрузки. Поэтому из значения вычитается число дней между датой в имени файла и датой выгрузки — получаем день лактации на дату данных.
2. **Фиксация на событии.** Если вычитание даёт отрицательный результат — программа зафиксировала день лактации на событии (перевод в сухостой, выбраковка), и значение в файле уже реальное. Таким коровам пересчёт не применяется, они перечисляются в примечании к таблице.
3. **Столбцы** в md: Номер животного | Группа | Статус | День лактации | Номер лактации | Продуктивность. Опускается только последний столбец выгрузки — «Пик прод-ть день».
4. **Служебные строки** (пустые, итог «T NNN») пропускаются.
5. **Результат** кладётся в подпапку `raw/excel/Excel-MD/<дата-данных>_dairyplan_produktivnost.md` (конвертированные md-таблицы — отдельно от исходных xlsx; дата в начале имени).
